# ملف الأعمال — نجلاء العتيبي

موقع شخصي ثابت (HTML و CSS و JavaScript فقط) جاهز للنشر على GitHub Pages. لا يحتاج خادمًا ولا خطوة بناء ولا اتصالًا بالإنترنت: الخطوط ومكتبة الرسوم مستضافة داخل المستودع.

---

## محتويات المستودع

```
portfolio/
├── index.html                      الصفحة الرئيسية
├── README.md                       هذا الملف
├── .nojekyll                       يمنع GitHub من معالجة الملفات ويحافظ على المجلدات كما هي
├── assets/
│   ├── css/style.css               تنسيق الموقع
│   ├── css/demo.css                تنسيق نماذج العرض
│   ├── js/content.js               ★ كل محتوى الموقع (عربي/إنجليزي) — عدّلي هنا
│   ├── js/main.js                  محرّك العرض وتبديل اللغة
│   ├── js/chart.umd.js             مكتبة الرسوم (مستضافة محليًا)
│   ├── fonts/                      الخطوط
│   ├── img/                        صور النماذج
│   ├── cv/Najla-AlOtaibi-CV.pdf    السيرة الذاتية للتحميل
│   └── logo/wds-logo.png           شعار معرض الدفاع العالمي (يظهر داخل النماذج فقط)
└── work/
    ├── actions-tracker.html        نموذج تفاعلي: لوحة متابعة إجراءات اللجان
    ├── dashboards.html             نموذج تفاعلي: لوحات المؤشرات التنفيذية
    └── Monthly-Task-Tracker-DEMO.xlsx   نموذج Excel للتحميل
```

جميع المسارات نسبية، فالموقع يعمل تحت `https://<اسم-المستخدم>.github.io/portfolio/` وتحت أي اسم مستودع آخر.

---

## أولًا: الرفع على GitHub

### الطريقة الأسهل (من المتصفح، بدون برامج)

1. افتحي [github.com](https://github.com) وسجّلي الدخول.
2. اضغطي **New repository**، واكتبي الاسم `portfolio`، واجعليه **Public**، ثم **Create repository**.
3. في الصفحة التالية اضغطي **uploading an existing file**.
4. افتحي مجلد المشروع على جهازك، وحدّدي **كل الملفات والمجلدات**، واسحبيها إلى صفحة GitHub.
   - مهم: اسحبي المجلدات نفسها (`assets` و `work`) لا محتوياتها فقط، حتى تبقى المسارات صحيحة.
   - ملف `.nojekyll` ملف مخفي؛ إن لم يظهر في نافذة الاختيار اضغطي `Ctrl + H` في ويندوز أو `Cmd + Shift + .` في ماك لإظهار الملفات المخفية.
5. اكتبي في خانة الوصف `first upload` ثم اضغطي **Commit changes**.

### تفعيل GitHub Pages

1. من المستودع، افتحي **Settings** ثم **Pages** من القائمة الجانبية.
2. في **Source** اختاري **Deploy from a branch**.
3. في **Branch** اختاري `main` والمجلد `/ (root)` ثم **Save**.
4. انتظري من دقيقة إلى دقيقتين، ثم حدّثي الصفحة. سيظهر الرابط في أعلى الصفحة بهذا الشكل:

```
https://<اسم-المستخدم>.github.io/portfolio/
```

هذا هو الرابط الذي تشاركينه مع جهات التوظيف.

### التحقق بعد النشر

- افتحي الرابط على الجوال وعلى الكمبيوتر.
- جرّبي قائمة الجوال (زر الثلاث شُرَط) وروابط التنقل.
- افتحي مشروعًا بزر «عرض المشروع»، واضغطي صورة لتكبيرها.
- جرّبي **تحميل السيرة الذاتية** و**تحميل النموذج التجريبي (Excel)**.
- افتحي النموذجين التفاعليين من قسم المشاريع الرقمية.

## ثانيًا: تحديث المحتوى

كل نصوص الموقع في ملف واحد: `assets/js/content.js`. الموقع بالإنجليزية فقط، فكل حقل نص واحد مباشر. لا حاجة لتعديل `main.js` أو `style.css`.

**إضافة خبرة جديدة** — انسخي كتلة كاملة داخل `experience.jobs` وعدّليها:

```js
{yrs:"2026 — Present",
 title:"Job title",
 org:"Organization",
 pts:[
   "Responsibility or achievement"
 ]},
```

**إضافة شهادة** — سطر واحد داخل `credentials.groups`:

```js
{label:"Certificate name", sub:"Issuer · Date"},
```

**إضافة مشروع** — انسخي كتلة داخل `projects.items`. الحقول: `title` و `sum` و `shots` و `goal` و `role` و `feats` و `proven` و `expected` و `links`.

أول صورة في `shots` هي صورة غلاف البطاقة، وبقية الصور تظهر داخل نافذة المشروع.

- `proven`: نتيجة مذكورة فعلًا في سيرتك أو ملفاتك. إن لم توجد اكتبي `proven: null` وسيختفي الصندوق تلقائيًا.
- `expected`: الفائدة المتوقعة من النموذج. هذا الفصل مقصود حتى لا تختلط النتائج المثبتة بالتوقعات.

**إضافة صورة لمشروع** — ضعي الصورة في `assets/img/` ثم أضيفي داخل `shots`:

```js
{src:"assets/img/image-name.jpg", cap:"Caption"},
```

الوصف في `cap` يُستخدم أيضًا كنص بديل (alt) للصورة، فاكتبيه بالإنجليزية.

**تحديث السيرة الذاتية** — استبدلي الملف `assets/cv/Najla-AlOtaibi-CV.pdf` بنسخة جديدة بالاسم نفسه. إن غيّرتِ الاسم، حدّثي السطر `cvFile` في أعلى `content.js`.

**تحديث الروابط أو بيانات التواصل** — كلها في أول كتلة `identity` في `content.js`.

بعد أي تعديل: ارفعي الملف المعدّل إلى GitHub (من صفحة الملف → أيقونة القلم → لصق التعديل → Commit)، وسيتحدث الموقع خلال دقيقة.

## ثالثًا: السرية ونماذج الأعمال

- جميع الأرقام والأسماء والتواريخ داخل النماذج التفاعلية وملف Excel **غير حقيقية بالكامل (fictional data)**، ولا تمثل أي بيانات فعلية.
- ملف Excel خالٍ من الأوراق المخفية والتعليقات وروابط البيانات الخارجية، وخصائص الملف لا تحمل أي معلومة عن جهة عمل.
- لقطات نظامي اللجان والوفود مأخوذة من بيئة عرض تجريبية، وأسماء الجهات فيها تحمل كلمة «تجريبي»، والأرقام الظاهرة ليست نتائج أعمال فعلية.
- يظهر في كل نموذج تنويه: «أُنجز العمل الأصلي أثناء عملي في معرض الدفاع العالمي. هذه نسخة عرض ببيانات غير حقيقية (Demo with fictional data) لحماية سرية المعلومات».
- شعار المعرض يظهر داخل نماذج الأعمال فقط، وهوية الموقع نفسه شخصية باسمك.

**لتغيير الشعار** — استبدلي `assets/logo/wds-logo.png` بملف آخر بالاسم نفسه.

## أسئلة شائعة

**الموقع يظهر بدون تنسيق بعد الرفع؟** غالبًا رُفعت محتويات المجلدات بدل المجلدات نفسها. تأكدي أن المستودع يحتوي على مجلد `assets` ومجلد `work` وليس ملفات متفرقة.

**الصفحة لا تفتح بعد التفعيل؟** انتظري دقيقتين ثم حدّثي؛ وتأكدي أن المستودع **Public** وأن الفرع المختار في Pages هو `main` والمجلد `/ (root)`.

**هل يعمل الموقع بدون إنترنت؟** نعم، إن فتحتِ `index.html` مباشرة من جهازك سيعمل كل شيء بما في ذلك الرسوم البيانية.
